# Retail Sales Performance Analysis TechBridge Data Analytics Internship (Capstone Project)

## Project Objective
To understand the company's sales performance and customer activity using raw transactional data. This project covers data cleaning, combining related tables, analysing the sales information, creating dashboard visualisations, and using SQL to answer business questions.

---

## Dataset Description
The analysis integrates three connected datasets containing a total of 150 original rows across the following relational schemas:

*   Customers Table (20 rows): `CustomerID`, `City`, and `CustomerType`.
*   Products Table (10 rows): `ProductID`, `ProductName`, `Category`, and `UnitPrice`.
*   Transactions Table (150 rows): `TransactionID`, `CustomerID`, `ProductID`, `TransactionDate`, `Quantity`, and `Discount`.

Key Fields for Analysis: `CustomerID`, `CustomerName`, `CustomerType`, `City`, `ProductID`, `ProductName`, `TransactionDate`, `UnitPrice`, and `Quantity`.

---

## Data Cleaning & Transformation
To ensure analytical consistency and accuracy, the following data cleaning operations were executed:
*   Referential Integrity Fixes: 
    *   Deleted an unmatched customer record (`C999`) from the transactions table since it did not exist in the Customers database.
    *   Deleted an unmatched product record (`P999`) from the transactions table since it did not exist in the Products database.
*   Anomaly Handling: Flagged transaction `T0120` which contained a corrupt negative quantity (`-2`) in the `Quantity` field for a Laptop purchase. This row was dropped from final aggregations to avoid a false negative variance of `-₦900,000.00` in the product category totals.
*   Deduplication & Null Checks: Verified that no duplicate rows or blank cells remained in any dataset.
*   Formatting: Applied the `TRIM` function across text columns to strip erroneous whitespace and cast field data types correctly.

Final cleaned transactional scope: 147 valid transactions.

## SQL Analysis

The following relational SQL queries were run on the cleaned database environment (`localhost\SQLEXPRESS`) to validate the spreadsheet logic:

### SQL Question 1: Total revenue generated by each product
```sql
SELECT 
	p.ProductName,
	ROUND(SUM((t.Quantity * p.UnitPrice) * (1 - t.Discount)),
		2) AS Revenue
FROM 
	productTable p
INNER JOIN transactionTable t
	ON p.ProductID = t.ProductID
GROUP BY ProductName
ORDER BY Revenue DESC
```

### SQL Question 2: Product category revenue ranking
```sql
SELECT 
	p.Category,
	ROUND(
	SUM(
		(t.Quantity * p.UnitPrice) * (1 - t.Discount)),
		2)
		AS Revenue
FROM 
	productTable p
INNER JOIN transactionTable t
	ON p.ProductID = t.ProductID
GROUP BY Category
ORDER BY Revenue DESC 
```

### SQL Question 3: Top-generating customers
```sql
SELECT 
	c.CustomerName,
	ROUND(
	SUM(
		(t.Quantity * p.UnitPrice) * (1 - t.Discount)),
		2)
		AS TotalRevenue
FROM 
	customersTable c
INNER JOIN transactionTable t
	ON c.CustomerID = t.CustomerID
INNER JOIN productTable p
	ON p.ProductID = t.ProductID
GROUP BY CustomerName
ORDER BY TotalRevenue DESC 
```

### SQL Question 4: City revenue breakdown
```sql
SELECT 
	c.City,
	ROUND(
	SUM(
		(t.Quantity * p.UnitPrice) * (1 - t.Discount)),
		2)
		AS TotalRevenue
FROM 
	customersTable c
INNER JOIN transactionTable t
	ON c.CustomerID = t.CustomerID
INNER JOIN productTable p
	ON p.ProductID = t.ProductID
GROUP BY City
ORDER BY TotalRevenue DESC 
```

### SQL Question 5: System average transaction value
```sql
SELECT 
	ROUND(
	AVG((t.Quantity * p.UnitPrice) * (1 - t.Discount)),2)
		AS AverageTransactionValue
FROM 
	transactionTable t
INNER JOIN productTable p
	ON t.ProductID = p.ProductID
```

### SQL Question 6: Revenue distribution by customer type
```sql
SELECT 
	c.CustomerType,
	ROUND(
	SUM(
		(t.Quantity * p.UnitPrice) * (1 - t.Discount)),
		2)
		AS TotalRevenue
FROM 
	customersTable c
INNER JOIN transactionTable t
	ON c.CustomerID = t.CustomerID
INNER JOIN productTable p
	ON p.ProductID = t.ProductID

```

## Key Insights & Business Recommendations

*   Optimize High-Margin Tech Sourcing in Key Hubs: Since Electronics (₦24.1M), Monitors (₦7.9M), and the city of Kano (₦7.2M) represent the core revenue pillars, stock allocation and regional marketing budgets should lean heavily into Northern fulfillment hubs to eliminate stockouts.
*   Establish Retail Loyalty & Mid-Year Campaigns: Retail customers capture over half of total revenue (₦23M+). To smooth out seasonal revenue dips (like the low point seen in June), the company should implement a consumer loyalty scheme alongside strategic Q2 promotions to encourage consistent order volume.
*   VIP Retention Management: Dedicated account managers or personalized incentives should be built around high-value accounts (e.g., Ibrahim Sani, Hauwa Ali, Tunde Adebayo) who skew overall performance and represent highly concentrated consumer value.
